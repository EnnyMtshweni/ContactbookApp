# Contact Book App

## Project Overview

The Contact Book App is a simple web application designed to store, manage, and organize contact information efficiently. The application allows users to add new contacts, view saved contacts, and delete contacts when they are no longer needed.

The goal of this project was to strengthen my understanding of JavaScript, DOM manipulation, CRUD functionality, and local storage while building a practical and user-focused application.

---

## Project Objectives

The main objectives of this project were to:

- Build a functional contact management system.
- Practice CRUD operations (Create, Read, Delete).
- Strengthen JavaScript DOM manipulation skills.
- Learn how to store persistent data using Local Storage.
- Improve UI structuring and user experience design.
- Develop problem-solving skills through real-world functionality.

---

## Features

### Add New Contacts
Users can add contact details such as name, phone number, and email.

### View Contacts
All saved contacts are displayed in a structured list format.

### Delete Contacts
Users can remove contacts that are no longer needed.

### Persistent Storage
Contacts are saved using Local Storage, ensuring data remains after page refresh.

### Dynamic Updates
The contact list updates instantly without reloading the page.

### Simple User Interface
Clean and easy-to-use interface for smooth navigation and interaction.

## Challenges Faced

### Managing Data Structure

Handling multiple contacts in a structured way required careful planning.

#### Solution
I used arrays of objects to store contact information efficiently.

---

### Keeping UI in Sync

Ensuring the interface updated correctly after every action was a challenge.

#### Solution
I re-rendered the contact list after each update to keep everything consistent.

---

### Data Persistence

Initially, data was lost after page refresh.

#### Solution
Local Storage was implemented to store and retrieve contact data automatically.
